# TraderPro — Advanced AI Trading Bot

An advanced, responsive trading bot platform built with Vite, vanilla JavaScript, and modern CSS. TraderPro provides real-time market analysis using 15 technical indicators and a premium, high-performance UI.

## 🚀 Features

- **Real-Time Market Data**: Live prices and ticker updates via Binance WebSockets.
- **Advanced Charting**: Custom candlestick charts with live price lines and signal markers.
- **Signal Engine**: Decision engine using 15 indicators (SMA, EMA, RSI, Bollinger Bands, MACD, etc.).
- **Signal Markers**: BUY/SELL markers rendered on the chart with Take-Profit and Stop-Loss levels.
- **Responsive Design**: Mobile-first UI with adaptive grid layouts and touch-friendly navigation.
- **News Terminal**: Real-time market news with automated sentiment analysis.
- **Portfolio Tracking**: Performance monitoring with equity curves and P&L breakdown.

## 🛠 Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Dev-Server**: Vite
- **Data Source**: Binance WebSocket API

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone [repository-url]
   cd TraderPro
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📈 Indicators Included
